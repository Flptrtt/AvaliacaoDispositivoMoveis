# AvaliacaoDispositivoMoveis
Repositório para entrega da avaliação do cliclo 1 de programaçao para dispositivos moveis

# Nome Completo
Filipe Trotte Rodrigues da Silva

# Descrição curta do app e dos três tipos de navegação.
 App para testar os três tipos de navegação 
 1.Stack -> navegação entre páginas seguindo um fluxo pré determinado.
 2.BottomTabs -> abas com páginas que são de acesso frequente como inicio ou perfil.
 3.Drawer -> paginas acessíveis através de um menu lateral ou menu sanduiche 

 # Como rodar o projeto:
 npm install e npx expo start

 # Como ativar o modo "aninhado"
 Entre na pasta routes e no index.jsx e mude o valor da constante TIPO_DE_NAVEGACAO para aninhado
